Git & GitHub Branch Workflow Task

Bu layihə Git branching iş axınını və GitHub üzərində versiya nəzarəti prinsiplərini praktiki şəkildə sınaqdan keçirmək üçün hazırlanmışdır.

Layihə Haqqında
Tapşırıq çərçivəsində aşağıdakı Git əməliyyatları icra edilmişdir:
- Əsas strukturun (`main`, `staging`, `develop`) qurulması.
- Lokal və uzaq (remote) serverlərdə `feature` branch-lərinin (`feature/html-page`, `feature/python-script`) yaradılması.
- Branch-lərin mərhələli şəkildə birləşdirilməsi (Merge) və sinxronizasiyası (`fetch`, `pull`, `push`).

Fayllar
- `index.html`: Sadə HTML strukturu
- `app.py`: Test məqsədli Python skripti
- `README.md`: Layihə haqqında ümumi məlumat
